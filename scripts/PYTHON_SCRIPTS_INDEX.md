# Python Scripts Index

This folder contains repo bootstrap, dashboard, CMS, R2, SQL, and deployment helper scripts used during the Leadership Legacy build.

## Scripts

- `build_full_dashboard.py`
- `collect_python_scripts.py`
- `generate_full_cms_sql.py`
- `upgrade_header_footer_auth.py`
- `wire_r2_website_bucket.py`

## Usage

Run scripts from the repo root unless a script says otherwise:

```bash
cd ~/Downloads/leadership-legacy
python3 scripts/<script-name>.py
```
